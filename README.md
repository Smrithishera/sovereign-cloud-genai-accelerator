# 🛡️ Sovereign Cloud GenAI Accelerator Workspace
**Live Infrastructure Deployment:** https://sovereign-cloud-genai-accelerator-portfolio-374650412951.asia-southeast1.run.app/

A production-grade reference architecture and interactive simulation sandbox natively engineered on **Google Cloud Run**. This workspace validates zero-trust ingestion, data perimeter isolation, and stateful multi-agent orchestration blueprints designed to align with strict **DACH-region enterprise compliance frameworks (GDPR, BDSG, and German Federal Data Sovereignty mandates)**.

---

## 🎨 Visual & Experiential Architecture

The application UI maps abstract cloud boundaries into discrete, operational control panels:

*   **Sovereign Ingestion Sandbox:** An interactive portal where evaluators can execute unstructured data payloads against pre-configured DACH enterprise profiles (`Münchener Automobilwerke AG`, `Zürich Alpine Biotech AI Ltd`, `Wiener Güterverkehr AG`). Users can toggle live edge-based GDPR sanitization and observe multi-agent cognitive routing state steps.
*   **Production Code Blueprints:** An integrated, copyable archive containing four production-ready, structurally validated configuration templates:
    *   *LangGraph Multi-Agent Router & Stateful GDPR Filter Loop*
    *   *Model Context Protocol (MCP) SAP Database Bridge Schema*
    *   *Sovereign Cloud Frankfurt Region (`europe-west3`) Terraform Infrastructure Blueprint*
    *   *Dual-Agent Execution Evaluation & Hallucination Scoring Script*
*   **Google Cloud FDE Experience Map:** An interactive matrix that maps core engineering competencies (`LangGraph State Engine`, `Data Sovereignty Perimeters`, `MCP System Integration`, `Vertex AI Quota Budgets`) directly to functional proof artifacts and active codebase locations within this repository.

---

## ⚡ Multi-Agent Observability & Infrastructure Telemetry

The control plane implements live monitoring of LLM-native infrastructure constraints and Service Level Indicators ($SLIs$):

*   **Real-Time Throughput Tracker ($Tokens/Sec$):** Simulates prompt processing velocities, scaling live metrics dynamically based on chosen underlying models (comparing latency-optimized `Gemini 3.5 Flash` execution pipelines against deep-reasoning `Gemini 3.1 Pro` layers).
*   **Vertex AI Quota Monitors:** Tracks simulated runtime token consumption boundaries against an isolated **5.0M TPM (Tokens Per Minute)** budget constraint and live TPU utilization metrics mapped to virtual Frankfurt cluster configurations.
*   **Model Context Protocol (MCP) Diagnostics:** Surfaces active connection streams mapping secure tools (`sap_read_table` and `sovereign_db_proxy`) to isolated database infrastructure without exposing underlying data networks.
*   **LangGraph Execution Trace:** Generates sequential, step-by-step trace logs tracking payload progression across Cognitive Routing, Edge Sanitization, Regionalized Grounding, and Hallucination Evaluation nodes.

## 🔒 Operational Excellence & Tech Stack

This project enforces strict compilation boundaries, optimized client bundles, and production-grade software craftsmanship:

*   **Runtime & Server Architecture:** Optimized via Node.js TypeScript execution primitives (`tsx server.ts`) and compiled using `esbuild` for ultra-low latency serverless container boots.
*   **Frontend Engine:** Built on React 19, TypeScript, and Tailwind CSS v4, managing responsive layouts and dynamic state management with minimal client-side friction.
*   **Interactive UX:** Features custom asynchronous clipboard-sharing mechanics with instant, non-blocking UI toast notifications for seamless developer use.
*   **Deployment Perimeter:** Packaged as a secure Docker container and deployed via a serverless execution pipeline onto **Google Cloud Run**.
